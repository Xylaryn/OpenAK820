# Changelog

## 0.1.0-alpha.1

First public test release.

- Key remapping on the top and Fn layers, macros, 20 lighting modes, per-key colours, real-time effects, music lighting, screen animation editor and uploads, clock sync, keyboard settings, profiles, and tray and autostart.
- USB and 2.4 GHz support. Real-time lighting and screen uploads need USB.
- Warns when other software is driving the keyboard, and reports a failure if it receives another program's reply.
- No network code, telemetry, automatic updates or firmware flashing.
